# v36 Evidence Package

이 디렉터리는 v36 active package에서 분리한 evidence package다.
원천 자료 clone, source application 증거, behavioral benchmark raw output, actor output, semantic judge 결과, ablation 결과, release decision 증거, validation run history, archive traceability 자료를 보관한다.

이 영역은 active runtime package가 아니며, v36 운영 문서는 필요한 경우 카테고리 수준에서만 이 위치를 참조한다.
