# Current Package Quality Score

`v36/`의 품질 기준은 현재 validation runner와 보존된 evidence를 기준으로 관리한다.

## Current quality surfaces
- Instructions: agent가 시작 경로를 찾을 수 있는가
- State: 다음 세션이 상태를 이어받을 수 있는가
- Verification: 완료 전에 증거를 요구하는가
- Scope: 작업 범위가 통제되는가
- Lifecycle: 시작과 종료가 표준화되어 있는가

## Claim rule
품질 claim은 실행된 검증과 보존된 evidence 범위를 넘지 않는다.
