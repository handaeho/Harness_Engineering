# Grounded Research Reference

Use this reference only after `grounded-research` activates and source authority affects the answer.

## Evidence Target

- Name the exact claim, source authority needed, freshness window, version or date boundary, and output shape.
- Use the smallest source set that can prove or disprove the claim.
- Prefer official OpenAI docs for Codex, OpenAI APIs, SDKs, models, and product behavior.
- Use repo-local files for project truth and preserve exact paths, identifiers, dates, versions, and line references when they matter.

## Source Ledger

Record:
- source id
- title
- URL or repo path
- source type
- checked date
- supported claims
- limitations or freshness risk

## Synthesis Rules

- Separate direct source facts from inference.
- Surface conflicts instead of smoothing them.
- Mark missing, stale-risk, or unsupported facts as `Need Verification`.
- Hand off implementation, design, or gate judgment to the owning skill once research is complete.
