# .gemini Directory

This directory stores project-local Gemini runtime assets.

Gemini project instructions live at:

```text
<project>/GEMINI.md
```

Gemini skills are stored in:

```text
<project>/.gemini/skills/*/SKILL.md
```

For coding, refactoring, tests, API contracts, data contracts, and Java/Python implementation work, also apply:

```text
<project>/.gemini/ENGINEERING_CONVENTION.md
```

Use these assets as Gemini runtime guidance only. Static validation does not prove live Gemini CLI loading, provider execution, release readiness, or production readiness.
