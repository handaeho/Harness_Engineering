# HARNESS Core Templates

이 디렉터리는 새 프로젝트나 외부 적용 모드에서 복사할 template asset을 둔다.

| 위치 | 성격 |
|---|---|
| `external-project/` | `<new-project-root>/.harness/harness-core/` vendored reference 구조에서 새 프로젝트 루트로 복사하는 기본 자산 |

정형 프로젝트 입력 reference template은 `docs/guides/PROJECT_INPUT_TEMPLATE.ko.md`에 있다.
실제로 채운 입력값은 새 프로젝트 루트의 `PROJECT_INPUT.md`에 둔다.
