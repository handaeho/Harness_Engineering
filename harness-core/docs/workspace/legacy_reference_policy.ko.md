# Legacy Reference Policy

Legacy reference 표현은 archive, compatibility, migration evidence처럼 historical context가 명시된 곳에서만 허용한다.

Active user/agent docs, profiles, CURRENT_STATE, clean export guidance에서는 `reference baseline`, `reference snapshot`, `historical reference`, `legacy reference`를 사용한다.

Legacy reference source는 현재 운영 대상이 아니며, clean export 또는 self-contained health check가 별도 source directory를 요구하지 않는다.
