# Agent Entrypoint Policy

`AGENTS.md` is an agent-facing runtime instruction file inside `harness-core`.

It must provide executable navigation, non-negotiable rules, claim boundary reminders, minimum validation commands, and pointers to authoritative source files.

It must stay compact and imperative. Human-facing explanation belongs in `README.md`, `docs/`, handoff files, and generated evidence records.

`AGENTS.md` alignment does not replace machine-readable gates and does not allow `stable`, `release-gated`, `production-ready`, `production-monitored`, `provider-diverse`, `provider-verified`, `adapter-checked`, `local-model-verified`, or `integration-verified`.
