# Asset Classes

The authoritative machine-readable asset class manifest is `MANIFEST.asset_classes.yaml`.

## Classes

- `core_source`: machine-readable or executable harness source, including stack manifest, schemas, tools, release gates, containment policies, and suite definitions.
- `agent_instructions`: agent-consumed runtime instructions such as `AGENTS.md`, `START_HERE_FOR_AGENTS.ko.md`, and `AGENT_BOOTSTRAP.ko.md`.
- `evidence`: generated or reviewed evidence and audit records under `evidence/` and `evals/reports/`.
- `human_docs`: README, docs, plans, and handoff files intended for human explanation or review.
- `generated_or_ignored`: install output or generated output that is not source-of-truth, including `node_modules/` and `dist/`.
- `reference_baseline`: historical reference snapshot under `evidence/reference-baseline/`, read-only.

## Edit Policy

Agent instructions may be edited only as runtime rules. Core source may be edited with validation. Evidence should be generated by runners or explicitly marked as review records. Human docs may be edited with claim boundary checks. Generated or ignored paths must not be manually edited. The reference baseline must not be modified manually.
