# Raw Storage Policy

Raw request and raw response dumps are not allowed in reusable evidence,
reports, docs, schemas, policies, tools, or handoff artifacts.

Allowed forms are previews, hashes, status summaries, usage summaries, redacted
request/response mappings, and booleans indicating whether raw payloads were
stored.

Forbidden forms include full raw request bodies, full raw response bodies,
authorization header values, environment secret values, and unredacted tool
payloads.
