# Agent Entrypoint Policy

`AGENTS.md` is the first file a new agent should read inside `prompt-stack-v2`.

It provides navigation, non-negotiable rules, claim boundary reminders, minimum validation commands, and pointers to authoritative source files.

It is intentionally compact. Detailed policy belongs in `core/`, `release/`, `security/`, `observability/`, `docs/`, and generated evidence records.

`AGENTS.md` alignment does not replace machine-readable gates and does not allow `stable`, `release-gated`, `production-ready`, `production-monitored`, `provider-diverse`, `provider-verified`, `adapter-checked`, `local-model-verified`, or `integration-verified`.
