# Evidence Lineage

Evidence lineage records how the current beta draft was built from existing
artifacts:
- v36 baseline
- alpha
- alpha-hardening
- beta-preflight
- beta-mock-execution
- OpenAI no-tool canary
- OpenAI structured output canary
- OpenAI tool-calling canary
- canary matrix summary and local readiness
- OpenAI tool-calling rerun
- OpenAI canary replay suite
- beta release evidence bundle draft

The lineage is generated from local files only. It does not perform provider
execution, local model execution, endpoint probing, or release gating.
